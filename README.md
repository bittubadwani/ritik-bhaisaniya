## 💻 Local Setup Instructions

Clone the repository and run locally:

```bash
# 1. Clone repo
git clone https://github.com/bittubadwani/ritik-bhaisrodiya.git

# 2. Navigate to project directory
cd ritik-bhaisrodiya

# 3. Install dependencies
npm install

# 4. Start development server
npx vite
```

Open your browser at `http://localhost:5173`.

### Production Build

```bash
# Compile production bundle
npx vite build
```

The optimized static assets will be generated inside the `dist/` directory.

---

## 🚀 Deploying to Vercel

1. Import this GitHub repository (`https://github.com/bittubadwani/ritik-bhaisrodiya.git`) into Vercel.
2. Select **Vite** as the framework preset (Framework: `Vite`).
3. Click **Deploy**. Vercel will automatically build and publish your site!
